Agreed Communication between Genios and MIDCA
-----------------
1. Midca gives move action, genios recieves it and sends the file

2. Genios goes to destination and surfaces, 
	Genios sends the file : file contains current position, actual trajectory (genios_out_loc)
	Genios sends another file: genios_out_search_latest
	
3. Midca now acknowledges that the action is complete

4. Midca gives another action, Genios sends another file: genios_out_move_latest or genios_out_search_latest

5. Genios dives down, and tries to achieve the action.
